Архитектурные решения

Прошивка — собственный форк flix (syrok_lite)
Свои optical flow (MTF-02), POS_HOLD, автопосадка и навигация, микшер с приоритетами, коррекция наклона, исправления защит и переходов режимов. Апстрим flix мониторится кроном ежечасно — полезное отбирается в заметку «flix — апстрим-коммиты и что внедрять».
Автономный образовательный дрон, не FPV
Камера — обзор с борта и vision-задачи, не видеотракт. Вся терминология проекта выверена под это (07.11.2026).
Электроника Лайта: ESP32-S3 SuperMini
IMU на SPI (не I2C — циклы 1–8 кГц и джиттер критичны), MTF-02 и ELRS на UART, делитель АКБ на ADC1 (GPIO9 — при Wi-Fi жив только ADC1), ToF-датчик — опция на I2C. INA226 на борту нет — измерение тока только на стенде. Питание логики 3,3 В: buck-boost по умолчанию, для Лайта рассматривается LDO с жёсткой автопосадкой при 3,7 В под нагрузкой + LiHV.
Моторы: 8520 → 615 для Лайта
Сейчас 8520 (~32 г тяги на мотор в сборке 75 г). Для Лайта (≤45 г, цель ≤35 г) — высокооборотные 615 ~70k rpm (~17 г тяги, класс ESP-FLY), 716 как альтернатива. Время полёта ~ масса^1,5: 75→40 г даёт ×2,5–2,9.
Силовой каскад: N-MOSFET + Шоттки
Сейчас 100N03A; SS34 обязателен (body diode). SI2300 допустим для 615, PMV16XN/IRLML6244 предпочтительнее. Причина потери тяги не подтверждена осциллографом — сравнение ШИМ 16/32/78 кГц и диоды на тензостенде.
Рама: PP + PETG-канопи
PP (LEGA RUBBER) — 0,90 г/см³, гнётся, гасит вибрации (как у Air65); цвет — канопи из светло-голубого PETG. Рама v0.2 = 6,7 г, путь дальше — 3 г Air65-класса на меньшей базе.
Стендовая программа
Тензодатчик YZC-133 + HX711 (30–55 г на мотор); гимбал на привязи (1 DoF → 3 DoF → свободный полёт): PID-настройка и диагностика без полётов; стендовый дрон с раздельным измерением тока по моторам (INA226/шунты) — честное сравнение 8520 vs 615 vs 716 и поиск «слабого» мотора. POS_HOLD по optical flow на привязи не тестируется (yaw «двигает» пол для флоу).

Открытые вопросы

POS_HOLD уходит по дуге после поворота
Гипотеза: рычаг MTF-02 от центра + вихрь от пропов. Лечение: компенсация рычага + notch-фильтр по измеренному спектру вибраций.
Потеря тяги
Обратные диоды на моторах не подтверждены осциллографом; сравнение ШИМ 16/32/78 кГц запланировано на тензостенде.
Нет измерения батареи и компенсации тяги
Делитель на ADC + компенсация падения напряжения по мере разряда, посадка при разряде. Связь Wi-Fi после arm — проверить.
